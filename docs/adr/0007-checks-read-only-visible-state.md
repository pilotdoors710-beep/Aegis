# Audit, Trials and Sybil judgement use only observable evidence

The Audit reads only what a person could read on the checkout. Trials judge only the Disposable copies' visible confirmations. Sybil scoring never sees ownership, attacker labels or domain names. None of them may read trap ids, arena storage, outcome JSON or evaluator truth, even though those are available in the same repo. Ground truth is for scoring the evaluation only. Reading it would make the defenses look perfect and prove nothing.
